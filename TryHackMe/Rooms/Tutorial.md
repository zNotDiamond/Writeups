#TryHackMe

### Deploying Your First Machine

There are two main ways to interact with TryHackMe virtual machines:

#### Option 1: AttackBox (Browser-Based)

+ The IP doesn’t load? Wait 1–2 minutes after clicking Start Machine. The page appears once the machine has finished booting.
+ Use http://, not https://, when you type the IP into the browser.
+ Free accounts get limited AttackBox time per day, which is plenty for this room.

#### Option 2: OpenVPN Access

+ Follow my step-by-step guides for Windows or Linux.
+ Use the machine’s IP in your personal browser to find the flag.

Flag :
`flag{connection_verified}`
