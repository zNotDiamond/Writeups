#TryHackMe

Which pillar of the CIA focuses on preventing unauthorized modification of data?

Answer: `Integrity`

Which pillar of the CIA focuses on preventing unauthorized access to data?

Answer: `Confidentiality`

Which CIA pillar ensures data is available to users when needed?

Answer: `Availability`

Which CIA pillar gets impacted if the data becomes untrustworthy?

Answer: `Integrity`

What is the term used collectively for all these pillars?

Answer: `CIA Triad`

What is the flag received after solving the exercise?

Answer: `THM{CIA_IS_ABOUT_BALANCE}`

Confidentiality = Keep it Secret
Only the right people can see the data.

Integrity
If data is changed without permission -> Integrity is broken

Availability = Keep it Accessible
You should be able to use your data or system when you need it.
If system is not working when needed -> Availability is broken
